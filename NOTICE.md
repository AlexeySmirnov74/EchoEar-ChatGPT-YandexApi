# Происхождение и лицензии компонентов

Проект объединяет компоненты с разными условиями. Универсальная лицензия MIT на весь репозиторий не заявляется; сохраняйте тексты лицензий и уведомления, относящиеся к соответствующим файлам и зависимостям.

Новые оригинальные дополнения этого проекта предоставляются по [MIT License](LICENSE). Это разрешение не заменяет лицензии и уведомления существующих компонентов, их исходных частей и зависимостей. В частности, сервер StackChan сохраняет AGPL-3.0-only.

| Компонент | Происхождение и условия |
| --- | --- |
| `firmware/` | На основе [Denis-VR/xiaozhi-esp32](https://github.com/Denis-VR/xiaozhi-esp32), снимок `41c79363538cce4513a1b4375758dd2f4f650fdb`. Основная лицензия прошивки — [MIT](firmware/LICENSE); отдельные включённые компоненты сохраняют свои лицензии. |
| `firmware/components/esp-ml307/` | [Apache License 2.0](firmware/components/esp-ml307/LICENSE). |
| Профиль EchoEar-2ST | При разработке использовалась документация [Muse gadget SDK](https://github.com/facebookincubator/muse-gadget-sdk/blob/8d32b7fa8d6d9b600ea65fc956e9418f5c778a28/esp32/devices/ostb-echoear-2st.md). Уведомление об источнике и MIT-лицензия последовательности инициализации дисплея сохранены в `firmware/main/boards/echoear-2st/echoear_display_init.h`. |
| `server/voice/` | На основе [StackChan AI Server](https://github.com/rudyll/stackchan-ai-server), [AGPL-3.0-only](server/voice/LICENSE); см. также [NOTICE](server/voice/NOTICE.md) и `server/voice/licenses/` для исходных частей M5Stack и других уведомлений. |
| `server/` | [Текст AGPL-3.0](server/LICENSE); лицензии включённых сторонних частей и библиотек сохраняются отдельно. |

В файлах исходников могут быть дополнительные уведомления об авторах и отдельных лицензиях. Зависимости ESP-IDF, Go, Python и контейнеров также имеют собственные условия; их нужно учитывать при распространении. Для модифицированного AGPL-сервиса, доступного по сети, см. условия предоставления соответствующего исходного кода в самой лицензии.

В интерфейсе сервера ссылка на исходники ведёт в [репозиторий проекта](https://github.com/AlexeySmirnov74/EchoEar-ChatGPT-YandexApi). Пока репозиторий закрытый, посторонние пользователи сервиса не смогут открыть эту ссылку. Владелец развёртывания отвечает за доступ к соответствующему исходному коду и текстам лицензий для своей конкретной сборки в соответствии с применимыми условиями; для точного соответствия следует сохранять идентификатор коммита или релиза. Открытие репозитория или ссылка на движущуюся ветку сами по себе не фиксируют исходный код конкретной установленной сборки.
