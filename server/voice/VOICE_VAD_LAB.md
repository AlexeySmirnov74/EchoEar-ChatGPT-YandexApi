# Лаборатория диагностики голоса

Копия исходников image-voice-6. Она не установлена на сервере.
Диагностические записи выключены по умолчанию: для включения лабораторного
эксперимента требуется обычный файл-маркер `/data/voice-events-enabled`.
Удаление маркера прекращает запись; ранее собранные файлы остаются до удаления.
Журнал `/data/voice-events.log` и один архив `.1` ограничены каждый 256 КиБ;
асинхронная очередь ограничена 64 событиями, при переполнении записи теряются.

Записи содержат только название события и причину из закрытого списка,
монотонное время от запуска процесса, длительность в миллисекундах и HMAC
случайного идентификатора сессии с идентификатором прослушивания. Ключ HMAC
случаен для каждого процесса и не сохраняется. Текст речи, аудиоданные,
адреса, идентификаторы устройства, сообщения об ошибках и секреты не пишутся.
`pause` — команда паузы, полученная от устройства; источник касания она
сама по себе не доказывает. При неизвестной причине поле `reason` отсутствует.
`vad_commit` и `vad_clear` обозначают решение VAD до отправки команды
провайдеру и не подтверждают её доставку.
Факт записи standby означает отправку команды, а не подтверждённую смену
состояния дисплея. Монотонные отметки связаны только с одним запуском сервера.

Синтетический тест `TestVoicePauseLab600Splits720msPause` проверяет паузу
720 мс между двумя блоками сигнала: VAD с тишиной 600 мс делит её на две
реплики; значения 900 и 1200 мс сохраняют одну. Это проверка алгоритма,
а не доказательство причины неисправности на колонке или оценка реальной
речи. Для отдельного последующего эксперимента можно рассмотреть значение
`ai.experimental_manual_silence_ms: 900`: относительно 600 мс оно увеличит
ожидание окончания речи на 300 мс. Перед установкой нужны независимая проверка,
тест реальных фраз и отдельное решение о развёртывании. Здесь значение VAD
и конфигурация работающего сервера не изменены.
