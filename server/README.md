# Сервер EchoWear

Это снимок исходников действующей системы, подготовленный для основной версии.
Он не устанавливает и не перенастраивает ничего на VPS.

- `voice/` — сервер на основе image-voice-8. Пример конфигурации безопасно
  отключает старый OTA и Home Assistant; адрес по умолчанию заменён на loopback.
  Ссылка на исходники в интерфейсе и её тест обновлены для этого проекта.
  Эти изменения отличаются от протестированного исходного снимка v8 и требуют
  отдельной пересборки и проверки перед установкой на работающий сервер.
  Дополнительно восстановлены
  файлы лицензий из архива исходного проекта. Исходные медиа и тестовый кадр
  нужны для `go:embed` и тестов.
- `gateway/gateway-alarm-clock.js` — работающий TLS/WebSocket шлюз; его
  SHA-256 совпадает с `/app/gateway.js` в контейнере VPS.
- `image-search/` — работающий поиск картинок и исходный рецепт образа.
  Четыре основных файла побайтно совпадают с контейнером `no-results-1`.
- `image-decoder/` — декодер и версия его зависимости `yandex_image_search.py`,
  считанная из контейнера `groupfix`. Эти файлы побайтно сверены с VPS.
  Поиск и декодер используют разные версии этого модуля. Не заменяйте одну
  другой без отдельного тестирования. Рецепт Docker для декодера восстановлен
  по аналогии и не подтверждён как побайтово идентичный текущему образу.

На VPS на момент снимка использовались образы `echowear/stackchan:image-voice-8`
(`sha256:e604007854579a242fa45b29dd9b1ffde83c478c2f19179f108d3fdec00d7bc1`),
`echowear/yandex-image-experiment:no-results-1`
(`sha256:c5ded6ac3970b3a649e9622efcd31dd35508e0955028297077d8a183216d4f5d`)
и `echowear/yandex-image-experiment:groupfix`
(`sha256:095cb646b41ac5bd1f3c4cb0a10b2e1b2f3b42dde01b156cbae5df1154be7021`).
Pillow в обоих контейнерах — 13.0.0; в копии сборочных рецептов эта версия
зафиксирована. Теги базовых образов не зафиксированы по digest: повторная сборка не
гарантирует побайтово идентичный образ.

Для сборки `voice` нужны Go 1.26, компилятор C, `pkg-config`, libopus и
libopusfile. Зависимости Go описаны в `go.mod`/`go.sum`. Контейнерную сборку
можно выполнить из каталога `server`:

```sh
docker build -f install/voice.Dockerfile -t echowear-voice:local .
```

Сборка загружает базовые образы и зависимости. Побайтовая идентичность
полученного контейнера ранее развёрнутому образу v8 не проверена.

23 ноября 2026 года изменённый снимок `voice/` вместе с
`install/voice.Dockerfile`, `install/standalone.sh` и
`install/voice-entrypoint.sh` был собран командой выше в тестовый образ с
локальным ID `sha256:b34c41b4dec124bd7e96ae9b1ef3ece4143942f32e7594c9d4f346fad2daa33c`.
В изоляции с фиктивным поставщиком проверены запуск, TLS/OTA и авторизованный
WebSocket до ответа `hello`; настоящий API не вызывался. Этот образ не был
установлен на работающий сервер. Чтобы связать его с публикуемыми исходниками,
сохраните коммит, содержащий эти файлы; само имя ветки может меняться.

Базовые образы тестовой сборки имели digest
`golang@sha256:23f198931d4bd83b4f5a613bd75656257ae8bf832dcbc2db80e1050b5219ca2a`
и `alpine@sha256:469c9ea410b9215eaee7976ba6c0639039b444be8e5d638f7abbada189971eb2`.
Рецепт использует теги, а версии системных пакетов не зафиксированы: повторная
сборка из этого коммита функционально проверяема, но не гарантирует тот же ID
Docker-образа. Доступ к реальному API и развёртывание на чистом VPS требуют
отдельной проверки.

В `voice/manifest/config/config.yaml` находятся безопасные исходные значения:
старый upstream OTA и Home Assistant выключены. Это не активная конфигурация VPS
и не готовый шаблон развёртывания. Не используйте файл для запуска без отдельной
настройки: рабочие настройки хранятся вне репозитория. Ключи, сертификаты,
конфигурация VPS, разговоры, журналы и резервные копии сюда не перенесены.

Лицензии исходного сервера и сторонние уведомления сохранены в `voice/LICENSE`,
`voice/NOTICE.md` и `voice/licenses/`; общий текст лицензии — `LICENSE`.
Проверка исходников на характерные форматы ключей и секретных адресов — это
дополнительная защита, а не гарантия отсутствия всех возможных секретов.
Смена исходников не переключает уже работающий сервер. Перед обновлением
существующего развёртывания сохраните его данные, секреты и Docker-образы.
