# Личная настройка OTA

В экспериментальной версии адрес задаётся в Wi‑Fi портале колонки: подключитесь к её точке настройки, откройте `http://192.168.4.1`, перейдите во вкладку «Дополнительно», укажите персональный HTTPS URL OTA и сохраните настройки. Подключите колонку к домашней сети; прошивка использует сохранённый адрес после перезапуска. Для WebSocket применяется тот же домен и порт. Неподходящий адрес отклоняется; старые сервисы по умолчанию не используются. Эта возможность относится к экспериментальным исходникам и требует отдельной проверки на устройстве.

Инструмент ниже пригодится, если вы хотите дополнительно задать резервный адрес при сборке. Он не обязателен при использовании портала:

1. Подготовьте ESP-IDF 5.5 и зависимости проекта. Перейдите в каталог `firmware`.
2. Выполните `python3 ../device/configure_ota.py` и введите HTTPS-адрес в скрытом приглашении. Скрипт создаст локальный файл `sdkconfig` из `sdkconfig.echowear-reference`, не перезаписывая уже существующую конфигурацию.
3. Проверьте параметры сборки и соберите прошивку командой `idf.py build`. Прежде чем записывать её на устройство, сохраните резервную копию и проверьте, что она подходит для вашей платы и таблицы разделов.

При вводе через портал адрес хранится в настройках устройства, а публичный шаблон и общий бинарный образ могут оставаться без персонального адреса. Если задали адрес при сборке, не публикуйте личный `sdkconfig` и собранный бинарник: адрес включается в оба файла. Публичный шаблон содержит неработающий пример. Чтобы изменить резервный адрес, сохраните или удалите старый локальный `sdkconfig` и повторите процедуру.

Проверка инструмента: `python3 -m unittest discover -s ../device -p 'test_*.py'`.
